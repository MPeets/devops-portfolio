01 / cloud-native-deployment-platform CI status

Cloud-native deployment platform

An API and a background worker on ECS Fargate in private subnets, behind a load balancer, with RDS Postgres and Secrets Manager. All of it in Terraform, shipped by GitHub Actions through OIDC with a gated apply. Also packaged as a Helm chart and smoke-tested in kind.

02 / airgapped-observability-lab CI status

Air-gapped observability lab

Prometheus, Alertmanager and Grafana for networks with no internet at all. Watches Linux and Windows hosts, probes devices that can't run an agent, and tracks certificates from an internal CA. Rules are unit-tested and the whole stack installs from a checksummed offline bundle.
