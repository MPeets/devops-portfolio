Air-gapped observability lab

Industrial and OT networks often have no internet at all, so monitoring has to arrive in a box and run on its own. This is that box. Every image pinned, every config in git, every alert rule tested, and an install that never reaches for a registry.

// 02 · BREAK SOMETHING

Pick a failure, watch the alert fire

These are the lab's real alert rules. Prometheus waits out the for: window, then Alertmanager routes the alert by severity. The metric data is simulated, the lifecycle is not.

TargetDown INACTIVE 
alert: TargetDown
expr: up{job!~"blackbox-(http|icmp|tls)"} == 0
for: 2m
labels:
  severity: critical
up{job="node"} now: 1 fires at 0
-12msimulated timenow
Alert lifecycle
  1. OKExpression is false. Nothing to do.
  2. PENDINGCondition is true. Waiting out for: 2m so a blip never pages anyone.
  3. FIRINGStill true after 2m. Prometheus sends it to Alertmanager.
  4. NOTIFIEDRouted to oncall and delivered to webhook-logger.

Probe jobs are excluded on purpose. ProbeFailed covers those, so one failure never raises two alerts.

// 04 · BUILT STEP BY STEP

Fourteen steps, each with a reason

Every step added one thing and wrote down why. Open one to read the decision. The full commit history is on GitHub.

01Scaffold with Prometheusdone

Versions pinned, UI bound to localhost. In an air-gapped network you only run what you bundled and checked, and Prometheus has no auth by default.

02node_exporter for host metricsdone

No published port. Only Prometheus can reach it over the Compose network, and host paths are mounted read-only.

03Grafana with a provisioned datasourcedone

The datasource comes from a file, so a fresh install needs zero clicking and comes up the same every time.

04Host dashboard as codedone

Dashboard JSON lives in git and loads at start. Reviewable, diffable, reproducible.

05Alert and recording rulesdone

Recording rules precompute the expensive queries and let one set of host alerts cover Linux and Windows.

06promtool unit tests for the rulesdone

Each alert gets synthetic series and an expected result. An alert that never fires is worse than no alert at all.

07Alertmanager routing and inhibitiondone

Critical to oncall, warnings to team, symptoms muted while the cause fires. Plus a Watchdog that proves the whole path is alive.

08blackbox_exporter probesdone

Checks from the outside for devices that can't run an exporter: does it answer, is it reachable, when does its certificate run out.

09Internal CA and certificate alertsdone

A lab CA and a tls-demo endpoint, so expiry alerts watch a real certificate. Nobody auto-renews anything inside an air gap.

10File-based discovery and Windows hostsdone

Targets come from files instead of a cloud API. Adding a Windows host is a one-line change, picked up within 30 seconds.

11Offline bundle with checksumsdone

Images and configs in one verifiable bundle. The installer refuses to start anything it can't verify.

12Hardeningdone

Read-only containers, NET_RAW as the only capability, non-root, localhost-only UIs, resource limits, bounded logs and storage, no outbound calls from Grafana.

13CI with an offline install rehearsaldone

Every push runs check.sh, shellcheck and the smoke test. Main also builds the bundle and installs it with registries blocked.

14Docs, runbook and OT notesdone

Architecture decisions, a runbook every alert links to, and notes on adapting the stack for OT sites.

// 05 · TAKING IT TO OT

What changes on a real industrial site

The lab is one network. The OT adaptation notes cover what it takes to run this next to real equipment.

01

Purdue model zones

Which level each piece lives on, and which flows are allowed to cross between levels.

02

Probing field devices safely

Gentle probes and sensible intervals. Some field equipment doesn't take kindly to being poked hard.

03

Maintenance windows

Planned work shouldn't page anyone. Silences cover the window, and alerts come back when it ends.

04

Hardened by default

Read-only, non-root, one capability, localhost-only UIs. The same defaults hold on a site as in the lab.
